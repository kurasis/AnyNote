# P16 final software acceptance archive

Public exact-source reports, GitHub ZIP digest receipts, actual Git input-byte
verification, normal29-job PR/main cohorts and guarded merge/environment receipts
are kept together here. Original report source SHAs and raw bytes are preserved.
The separate Git evidence branch leaves checked main unchanged.

This archive does not assert physical100GB capacity, owner-device acceptance,
qualified independent security review, production deployment or fresh cloud-task
restoration. The default cloud startup is P03/P06 plus local P16 checks; full
production-template acceptance self-starts isolated test projects on sized hosts.

The original retained baseline is unchanged. Exactly3 additive migrations/2 tables
were verified. One inadvertently invoked maintenance command removed18 expired
transient authentication rows; its explicit deviation receipt is separate from
strict unchanged checks on every original non-rate table/content/session/file.
No private SQL, recovery kit, signing/decryption key or encrypted backup is archived.

The archive-only secret-scan overlay extends the unchanged source policy. Its
exceptions bind exact receipt paths and complete SHA-256 lines to actual Git
blob bytes; altered hashes, wrong inputs/paths and added PAT/age identities
still fail. The adjacent bindings/negative-case receipt document the controls.
Raw report bytes are never redacted or normalized. Reproduce the complete scan
from a clean `git archive` export root with the overlay under this directory;
never scan/export private ignored workspace runtime state as public evidence.

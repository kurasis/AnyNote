# P18 evidence

P18 implements software review packaging, linked synthetic final journey, offline
exact-byte acceptance and user/operator handoff. Final PR/main and immutable raw
archive references are recorded after execution; this source file does not claim
that a future commit already passed CI.

The ordinary30-job cohort remains mandatory. Its28 original ZIPs include the
three versioned candidates and reports added to existing Windows/PWA/operations
artifacts, plus executed candidate-negative results in the security artifact.
`scripts/p18-acceptance.py` verifies inherited runtime assertions, every package
and source archive before emitting the95-case plus7-gate matrix and checksums.
Original PR/main receipts are separate. Development/failed runs are preserved
under their actual source and status, never renamed final PASS.

Candidate binaries/images remain in versioned Actions attachments and the local
offline review set; Actions retention is14days. The permanent evidence archive
retains original raw JSON, ZIP digests, job/source/input bindings, candidate
manifests, acceptance/checksum records and archive provenance, not private keys
or user profiles. No production publication is implied. See [P18 scope](../../P18_RELEASE.md).

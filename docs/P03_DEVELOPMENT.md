# P03 repository and development foundation

P03 deliverables are complete: pinned monorepo tooling, synthetic services,
initial OpenAPI, generated TypeScript/PHP DTOs, schema/drift checks, strict common
errors/request IDs and content-free logging. This is development infrastructure,
not account/device authorization, product storage, crypto adapters or deployment.
P02 design is verified; qualified review and G2/G3 remain open.

## Fresh clone and targeted checks

Use the existing checkout in cloud tasks. On Linux x86_64 with Docker/Compose,
Python 3.12.14 and a non-root developer UID, from the repository root:

```sh
bash scripts/install-p01-toolchains.sh
source scripts/runtime-env.sh
npm --prefix packages/protocol ci --ignore-scripts --cache /tmp/anynote-npm --no-audit --no-fund
npm --prefix packages/api-client ci --ignore-scripts --cache /tmp/anynote-npm --no-audit --no-fund
python3 scripts/install-p03-tools.py
python3 scripts/install-p02-tools.py
python3 scripts/dev-stack.py install
bash scripts/p03-checks.sh
python3 scripts/api-inventory.py
python3 scripts/check-secrets.py
```

The target command checks generated bytes, nine actual changed-input/output
negatives in isolated temporary copies, syntax, strict TypeScript and five client
contract tests, 11 PHPUnit tests, actual database transactions/outage recovery,
HTTP through Nginx/FPM and persisted content-free logs. Native extensions, Pint,
Composer/platform/advisory checks and origin/path/binding/user isolation remain
mandatory. Hosted CI starts from a clean checkout; local evidence retains its
actual dirty/base stamp and source hashes. Audit status is time-dependent.

`dev-stack.py` install/up/check/test/stop never resolves dependency versions,
rewrites lockfiles, generates fixtures/contracts or migrates product data.
Only its marked synthetic Compose project is controlled. State/credentials in
ignored `.local/p03` and its retained DB volume must stay together. Stop through
`python3 scripts/dev-stack.py stop`; no global prune/volume deletion. Live
processes must restart after environment restoration. Images are digest pinned;
signed Debian metadata/package hashes and HTTPS verification stay enabled.
Transitive OS packages remain repository-resolved; no reproducible release image
or full SBOM claim is made. Injected public proxy CA copies are ignored local
trust anchors, never credential extraction or a verification bypass.

## Authoritative and generated contracts

`packages/contracts/p03-operations.json` lists 79 required operations from original
chapter 08. `p03-api.schema.json` adds closed foundation capabilities/liveness and
initial snapshot/ack transports over frozen P02 types. The five P02 profiles and
all prior schema/vector/lock bytes are preserved. `generated/openapi.json` is
OpenAPI 3.1 with embedded resolvable schemas, fixed error mappings, exact path
parameters and explicit phase/implementation markers. Capabilities and liveness
are the only implemented public operations. Unknown phase-owned transport
wrappers remain explicitly unavailable (`never` in operation types), rather than
a permissive generic object or dummy authentication endpoint. P04–P13 finalize
them before accepting requests. Binary chunk shape is declared, not served.

`python3 scripts/p03-contracts.py --write` is an explicit development generator.
Default invocation/setup/CI only compare. It emits 157 schema-derived types,
readonly PHP DTOs, an original-ID runtime schema bundle and exact input/output
hash records. Source hashes bind protocol predicates, authoritative schemas,
registry, contract text and dependency metadata. All 157 schemas compile under
strict maintained Ajv; generated TypeScript compiles with strict nullability,
exact optional properties and checked indexed access. Five expected type errors
ensure invalid literals, unknown fields/codes and false capability claims fail.
PHP DTOs constrain primitive fields/required construction, not nested schema,
signature or current authorization; actual request-specific validators are P04/P05.
Generated PHP is independently syntax checked and excluded by exact Pint `notPath`;
handwritten PHP is formatted/linted. EditorConfig specifies UTF-8/LF/indentation.

## Request and error boundary

`/api/v1/capabilities` returns a configured stable 16-byte canonical base64url
service ID, exact five-component p02-v1 negotiation, decimal-string limits and
false product features. Missing/invalid production service configuration fails
closed. It never derives service identity from an untrusted Host. Public liveness
contains only `status: live`. Operator/dependency readiness and the temporary SQL
probe remain local/testing-only and deny production.

Every Laravel boundary response gets a fresh CSPRNG 16-byte canonical base64url
request ID; incoming IDs are ignored. Structured errors follow all 39 HTTP P02
mappings; three local-only errors cannot become server responses. Authorization,
missing-resource and method-denial exceptions conceal existence as NOT_FOUND.
Unexpected exceptions become generic TEMPORARY_UNAVAILABLE without debug/SQL/
path/stack strings, even if framework debug is accidentally enabled. Details are
empty by default; trusted application values are narrowed to canonical public
heads/counters and bounded retry hints. NOT_FOUND/ACCESS_REVOKED discard details.
Only transient errors send Retry-After (1–60 seconds). P04 must authorize a
resource before supplying any diagnostic head or storage detail.

The raw control boundary observes the 4 MiB limit, validates UTF-8/native JSON,
rejects duplicate keys including escaped aliases, nonfinite numbers, scalar roots
and depth over 32. It is common framing, not general cryptographic acceptance.
Nginx rejects an oversized ordinary or chunked body and invokes FPM with no body
and a trusted server-only FastCGI marker, producing the same canonical 413 error.
A client header cannot forge that marker. Native PHP upload/control ceilings are
4 MiB. P12 must implement a separate bounded authorized 8,388,624-byte binary
chunk path; the development control ceiling does not reduce the 1 GB file limit.

Configured app Origin is exact, with credentialed CORS, Vary and exposed request
ID/Retry-After. Hostile siblings and unsupported preflight headers are denied.
Local HTTP is only loopback synthetic tooling. Production API requests require
HTTPS; arbitrary X-Forwarded-Proto cannot assert it. Proxy/TLS/issuer trust, CSRF,
real cookies/bearer/device sessions and native redemption remain P06/P16. CORS
is not authorization or CSRF protection. PHP cannot serve/write the separate
static origin; only Nginx publishes loopback port 18080, DB/FPM publish none.
Set ANYNOTE_DEV_PORT before first project initialization to use another port.
The targeted HTTP wrapper reads that marked project's persisted port; it never
requires a duplicate setting or accepts an arbitrary network origin. Alternate
port native/HTTP checks were exercised and the original owned config restored.

## Logs, evidence and boundaries

The sole default logger uses a content-free Monolog formatter. Arbitrary log
messages become a constant event; exception/extra/context fields are discarded
except fixed event/code/route/method, fresh request ID, status and bounded duration.
No URLs/query/IP/account/object identifiers, bodies/ciphertext/keys/tokens/cookies,
SQL/path/stack interpolation is allowed. Each record is below 512 bytes. Owned
mode-0600 daily logs retain seven days; total volume monitoring/rotation belongs
to P16. Emergency output is /dev/null; native PHP errors and Nginx access/error
logs remain disabled. HTTP tests poison body, query, cookie and bearer data then
inspect persisted records without uploading raw logs.

Content-free artifacts are `artifacts/p03/foundation-report.json` and
`http-contract-report.json`, stamped with actual commit/dirty status and input
hashes. Ignore stale reports. Never upload .local/.env/vendor/logs or dump container
configuration. Scanner checks all Git-visible source plus nine fake-token paths,
15 changed-field negatives, old PUBLIC fragment mutation and alternate age key;
this task adds no scanner exceptions. New hash receipts use path/hash records to
avoid a generic API-key heuristic without suppressing any value.

TypeScript 7.0.2 / Apache-2.0 and exact Ajv dependencies have a separate frozen
lock/inventory; platform-optional compiler records are retained. Existing npm,
Composer/Cargo locks and P01 kits/reference bytes stay unchanged. Project release
license is unselected; scoped P01 GPL notices and upstream licenses remain.
No product account/schema, actual login/passkey/device proof, immutable SQL
revision/quota/sync/restore, production TLS or physical acceptance is claimed.
Qualified review is tracked but unbooked/not run. Next: P04 model/authorization
foundation, coordinating signature acceptance with P05 adapters and fixtures.

Rollback: ordinary revert and stop only the owned synthetic project. No production
schema/data/format migration or test-kit release is included.
